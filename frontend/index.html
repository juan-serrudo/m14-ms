📋 Características Implementadas

  • Separación por Dominio: Users y Password como microservicios independientes
  • Comunicación Síncrona: HTTP entre microservicios
  • Patrón Retry: Reintentos automáticos en llamadas HTTP (2 reintentos, timeout 2s)
  • Circuit Breaker: Protección contra fallos en cascada (umbral: 5 fallos, cooldown: 15s)
  • Load Balancer: NGINX distribuyendo carga entre 2 réplicas de users-service
  • Bases de Datos Independientes: SQLite separado por microservicio
  • Docker Compose: Orquestación completa del sistema
